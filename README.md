# AceSphere Tennis

Premium tennis e-commerce website starter built with Next.js, React, TypeScript and Tailwind CSS.

## Upload to GitHub

Upload the full contents of this folder to a GitHub repository named `acesphere-tennis`.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import the GitHub repository into Vercel and deploy. Add the Shopify environment variables when ready.

## Environment variables

Copy `.env.local.example` to `.env.local` and add your Shopify Storefront API details.
